# 印匠 · 印刷老师傅智能体

一个 PC 端的 AI 应用原型：以「印刷老师傅」的口吻，基于可替换的知识库回答问题，每条回答都给出引用出处。

## 怎么打开

直接双击 `index.html` 即可（file:// 协议已实测可用）。也可以起一个本地服务：

```bash
cd printing-master-agent
python -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123/index.html
```

无需安装依赖、无需后端、无需 API Key。

## 页面结构

| 区域 | 内容 |
| --- | --- |
| 左上角 | 品牌标识 + 「智能体 / 工具」页面切换 |
| 左侧栏 | 对话记录（可新建、切换、删除，自动按首句命名，本地持久化） |
| 主区上方 | 封面：CMYK 叠印色环 + 色标条 + 套准十字（纯 CSS 绘制，不依赖图片）；开始对话后自动收起为窄条，可手动展开 |
| 主区下方 | 对话区：气泡消息、要点列表、💡 提醒、出处标签、延伸问题 |
| 右侧栏 | 知识库窗口：拖拽/点击上传、搜索、启用停用、内容预览、重置 |
| 工具页 | 工具中心（6 个工具卡片，均为「待开发」占位） |

## 知识库怎么替换

三种方式，任选：

1. **右侧窗口上传**：把 `.md / .txt / .csv / .json` 文件拖进「把资料拖进来」区域，或点击选择。上传后立即参与检索，只有用户上传的文件可以删除。
2. **改内置数据**：编辑 `data/knowledge.js`，按现有结构增删文件即可。文件内容用 `## 小节标题` 分节，检索以「小节」为最小单元。
3. **停用/启用**：知识库列表里点电源图标，可临时把某份资料排除在检索之外。

## 检索原理（`js/engine.js`）

纯本地实现，不联网：

- 中文 bigram / trigram 切分 + 英文数字词 + 同义词表扩展（`烫金→烫印/电化铝`、`掉色→掉墨/附着力` 等）
- IDF 加权 + 小节标题加权 + 要点词条（术语行开头）加权，长度归一化避免长条目占优
- 命中后从多个命中块里择优抽取要点，附出处（文件名 + 小节名）与延伸话题
- 离题问题会明确回「未命中知识库」，不编造答案

想调整回答风格，改 `js/engine.js` 里的 `OPENERS`（开场话术）和 `answer()`。

## 文件结构

```
printing-master-agent/
├─ index.html            页面结构
├─ styles.css            样式（浅色 / 圆润 / CMYK 点缀色）
├─ js/
│  ├─ engine.js          检索问答引擎（浏览器与 Node 通用）
│  └─ app.js             UI 逻辑：会话、消息渲染、知识库管理
├─ data/knowledge.js     内置知识库（9 份资料 / 35 个知识小节）
└─ tools/                开发辅助脚本（不影响应用运行）
   ├─ prepare-art.py     把 AI 生成插画的棋盘格背景处理成透明底（备用）
   ├─ test-engine.js     命令行批量测试检索命中情况
   ├─ make-test-page.py  生成临时测试页，便于用无头浏览器截图核对 UI
   └─ source-art-original.png  早前生成的插画原图（已不再被界面引用，仅作存档）
```

> 界面目前不含任何图片资源：封面装饰与消息头像（「印」字徽标）都是纯 CSS 实现的。

## 已知边界

- 会话与上传的资料存在浏览器 localStorage，换浏览器不共享；清缓存会丢。
- 检索是关键词/统计匹配，不是语义向量检索；问法太绕或同义词表没覆盖时可能落到「未命中」，此时换个具体说法即可。
- 工具页是占位，功能未实现。
